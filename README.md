## Contenido

### 🐍 Taller de Python
Introducción y fortalecimiento de los fundamentos de Python.

Temas: cadenas de caracteres, tuplas, listas, conjuntos, diccionarios, condicionales, bucles, funciones, clases y Matplotlib.

[Ver Taller](taller-python)

### Taller Apache Spark

Introducción al procesamiento de datos y machine learning distribuido con Apache Spark.

Temas: SparkSession, DataFrames, exploración y preparación de datos, feature engineering, escalado y modelos de clasificación.

[Ver Taller](taller-spark.ipynb)

### Simulador Interactivo MapReduce

Simulador interactivo para comprender la arquitectura, el particionamiento de datos y la planificación de tareas en el modelo MapReduce.

Temas: particionamiento en chunks, planificación de tareas (Mappers y Reducers) en nodos físicos, fases de Map, Shuffle/Sort y Reduce, funciones de agregación y métricas de rendimiento en tiempo real.

[Ver Simulador](mapreduce_simulador_Ramirez.html)

### Simulador Apache Spark MLlib - Regresión

Simulador interactivo para el aprendizaje supervisado con modelos de regresión lineal utilizando Apache Spark MLlib.

Temas: regresión lineal con Mínimos Cuadrados Ordinarios (OLS), métricas de evaluación (MSE, RMSE, MAE, R²), experimentos de carga y fundamentos matemáticos.

[Ver Simulador](Ramirez_SimuladorMLlib.html)

### Taller PySpark - Predicción de ACV (Stroke)

Implementación y evaluación de modelos de machine learning distribuidos con PySpark MLlib bajo la metodología CRISP-DM para predecir accidentes cerebrovasculares.

Temas: metodología CRISP-DM, limpieza y diagnóstico de datos, análisis exploratorio univariado y bivariado, feature engineering (VectorAssembler, StringIndexer) y modelos de clasificación (Regresión Logística, Decision Tree, Random Forest, GBT).

[Ver Taller](RamirezTallerStroke.ipynb)
