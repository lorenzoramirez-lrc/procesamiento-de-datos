Fundamentos Didácticos

Marco Teórico y Matemáticas de la Regresión

Conceptos clave del aprendizaje supervisado continuo, derivación de parámetros, división de conjuntos y métricas de error.

1. ¿Qué es la Regresión?

Supervisado

El aprendizaje supervisado utiliza ejemplos históricos anotados $(x_i, y_i)$ para aprender una función predictiva $f(x) pprox y$.

Regresión: Predice valores numéricos continuos (ej. precios, temperaturas, tiempo de ejecución, consumo eléctrico). Clasificación: Predice etiquetas discretas o categorías (ej. spam / no spam, detección de fraude sí/no).

El objetivo de la regresión es encontrar la función que minimiza el error entre el valor real observado $y_i$ y la estimación $\hat{y}_i$.

2. Ecuación de Regresión Lineal

Modelo Lineal
y = β0 + β1x + ε
β0 Intercepto: valor estimado de y cuando x es exactamente 0 (punto de corte vertical). β1 Pendiente: razón de cambio en y por cada unidad que aumenta la variable x. x Variable independiente: atributo de entrada o feature predictora. y Variable dependiente: etiqueta continua o target a predecir. ε Término de error: residuo aleatorio no explicado (ruido Gaussiano ε ~ N(0, σ²)).

3. Mínimos Cuadrados (OLS)

Optimización

Buscamos minimizar la suma de residuos al cuadrado: $S(β_0, β_1) = \sum (y_i - (eta_0 + eta_1 x_i))^2$. Al igualar sus derivadas parciales a cero se obtiene la solución analítica exacta:

β1 = Cov(X, Y) / Var(X) = ∑(xi - x̄)(yi - ȳ) / ∑(xi - x̄)²
β0 = ȳ - β1x̄
En Spark MLlib: Las sumatorias (∑x, ∑y, ∑x², ∑xy, n) se calculan paralelamente en las particiones de datos usando un treeAggregate en una sola pasada $O(n)$, comunicando únicamente escalares al driver.

4. División Train / Test

Generalización

Evaluar un modelo únicamente con los datos con los que fue entrenado genera un sesgo optimista que oculta el sobreajuste (overfitting).

Train (70-80%): Conjunto exclusivo para el aprendizaje de los coeficientes β0 y β1. Test (20-30%): Conjunto ciego retenido para medir el rendimiento sobre datos nunca vistos. Fuga (Leakage): El modelo jamás debe ver las etiquetas ni estadísticas del conjunto de prueba durante su ajuste.

5. Métricas Matemáticas de Evaluación

Evaluación Cuantitativa
RMSE (Root Mean Squared Error) √[ ∑(y - ŷ)² / n ]

Raíz del error cuadrático medio. Está en las mismas unidades que la variable Y. Penaliza fuertemente errores grandes debido a la elevación cuadrática.

MSE (Mean Squared Error) ∑(y - ŷ)² / n

Promedio de los residuos al cuadrado. Función de pérdida estándar en optimización convexa, pero sus unidades están elevadas al cuadrado.

MAE (Mean Absolute Error) ∑|y - ŷ| / n

Promedio de los errores absolutos. Es mucho más robusto frente a valores atípicos (outliers) porque no magnifica los errores extremos.

R² (Coeficiente Determinación) 1 - (SSres / SStot)

Proporción de la varianza total de Y que el modelo logra explicar. 1.0 es ajuste perfecto; 0.0 equivale a predecir la media ȳ; valores negativos indican un modelo pésimo.

Curva de Escalabilidad: Tiempo de Ejecución vs Volumetría

Escala O(N)

Comportamiento en JS (Monohilo)

En JavaScript, el cálculo corre en un solo hilo con un límite de memoria asignado al navegador (heap de V8). Con 50.000 registros la complejidad lineal $O(N)$ tarda unos pocos milisegundos, pero al superar millones de registros se produciría un desbordamiento de memoria o congelamiento de la pestaña.

Escalado en Apache Spark MLlib

Spark soluciona esto dividiendo los datos en miles de particiones distribuidas sobre múltiples Worker Nodes. Cada nodo calcula localmente los acumuladores de suma ($\sum x, \sum y, \sum x^2, \sum xy, n$) sobre sus particiones en RAM.

Reducción en Árbol (TreeAggregate)

Gracias al algoritmo treeAggregate, las sumas parciales se combinan jerárquicamente. Hacia el nodo Driver solo viajan unos pocos bytes de escalares en lugar de terabytes de datos brutos, permitiendo entrenar sobre 100.000.000 de registros sin colapso de red.

Flujo de Ejecución Distribuida de Regresión en Clúster Spark

Pipeline Completo de Regresión Lineal en PySpark (Spark MLlib) 
# ==============================================================================
# APRENDIZAJE SUPERVISADO: REGRESIÓN LINEAL DISTRIBUIDA CON APACHE SPARK MLLIB
# Autor: Lorenzo Ramirez Calderon (ID: 20550074) - Procesamiento a Gran Escala
# ==============================================================================

from pyspark.sql import SparkSession
from pyspark.ml.feature import VectorAssembler
from pyspark.ml.regression import LinearRegression
from pyspark.ml.evaluation import RegressionEvaluator

# 1. Inicialización de SparkSession en clúster
spark = SparkSession.builder \
    .appName("RegresionSupervisada_SparkMLlib") \
    .config("spark.sql.shuffle.partitions", "8") \
    .getOrCreate()

# 2. Carga y preparación del DataFrame distribuido (simulando X e Y)
# data_df contiene columnas: 'x' (independiente) e 'y' (dependiente continua)
assembler = VectorAssembler(inputCols=["x"], outputCol="features")
dataset = assembler.transform(raw_df).select("features", "y")

# 3. División aleatoria sin fuga de datos (75% Train, 25% Test)
train_df, test_df = dataset.randomSplit([0.75, 0.25], seed=42)

# 4. Instanciación del estimador de regresión lineal
# regParam: penalización L2 (Ridge). elasticNetParam=0.0 equivale a L2 puro.
lr = LinearRegression(
    featuresCol="features",
    labelCol="y",
    regParam=0.0,              # Equivalente a OLS si es 0.0
    elasticNetParam=0.0,       # 0.0=Ridge (L2), 1.0=Lasso (L1)
    maxIter=100
)

# 5. Entrenamiento distribuido del modelo (Mínimos Cuadrados en clúster)
model = lr.fit(train_df)

# 6. Extracción de los parámetros aprendidos
slope = model.coefficients[0]
intercept = model.intercept
print(f"Ecuación aprendida: y = {intercept:.4f} + {slope:.4f}*x")

# 7. Inferencia distribuida sobre el conjunto de prueba retenido
predictions = model.transform(test_df)

# 8. Evaluación rigurosa de métricas de generalización
evaluator_rmse = RegressionEvaluator(labelCol="y", predictionCol="prediction", metricName="rmse")
evaluator_r2   = RegressionEvaluator(labelCol="y", predictionCol="prediction", metricName="r2")
evaluator_mae  = RegressionEvaluator(labelCol="y", predictionCol="prediction", metricName="mae")

print(f"RMSE Test: {evaluator_rmse.evaluate(predictions):.4f}")
print(f"R²   Test: {evaluator_r2.evaluate(predictions):.4f}")
print(f"MAE  Test: {evaluator_mae.evaluate(predictions):.4f}")
